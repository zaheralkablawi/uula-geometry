# UULA Geometry

رسم الأشكال الهندسية (المستوية والدائرة والمجسمات) وإدراجها في الباوربوينت أشكالًا قابلة للتعديل، وفي الوورد صورةً.

- `taskpane.html` يفتح دائمًا أحدث `app.html`.
- `python3 build.py` يبني `app.html` من `src/app.template.html` (ويضيف خط UULA Sans).
- تفتحها UULA Toolkit مباشرة من هذا المستودع.
